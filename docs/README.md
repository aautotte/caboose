# Caboose user guide

How to do things in Caboose, one page per area. For what Caboose is and how to build it, see the
[main README](../README.md).

Caboose runs the git installed on your computer. Whatever it does, you can see the exact command in the
[Git activity log](everything-else.md#git-activity-log) and run it yourself.
